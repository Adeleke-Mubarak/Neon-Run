# Character Roster Specification — Neon Run: Fracture

The game features an extensible character architecture decoupled from hardcoded models. Every runner is defined by `CharacterData`.

---

### Character 1: KAI (The Core Runner)
- **Role:** Balanced Runner
- **Personality:** Calm, observant, competitive street racer.
- **Visual Identity:** Sleek aerodynamic jacket with turquoise cyan bioluminescent trim, athletic stance, high-visibility visor.
- **Stats:**
  - Base Speed Modifier: 1.0x
  - Jump Modifier: 1.0x
  - Slide Modifier: 1.0x
  - Phase Shift Modifier: 1.0x
- **Ability:** *Quick Phase* — Initiates an immediate short Phase Shift burst to bypass incoming bottlenecks.
- **Unlock Requirement:** Default / Unlocked from start.

---

### Character 2: ZARA (The Phantom)
- **Role:** Agile Runner
- **Personality:** Fast-talking courier, lightning reflexes.
- **Visual Identity:** Lightweight carbon-fiber synthwear, magenta glowing braids, low-profile kinetic sneakers.
- **Stats:**
  - Base Speed Modifier: 1.05x
  - Jump Modifier: 1.15x
  - Slide Modifier: 1.10x
  - Collision Forgiveness: 0.85x
- **Ability:** *Ghost Step* — Phasing dodge allowing intangible pass-through of one physical obstacle.
- **Unlock Requirement:** Reach 10,000m total distance or 5,000 Credits.

---

### Character 3: JAX (The Juggernaut)
- **Role:** Power Runner
- **Personality:** Ex-demolition engineer, fearless brute-force specialist.
- **Visual Identity:** Heavy cybernetic exo-suit, bright amber/gold hazard plating, shockwave gauntlets.
- **Stats:**
  - Base Speed Modifier: 0.95x
  - Jump Modifier: 0.90x
  - Obstacle Interaction: Breakable clearance
  - Risky Route Multiplier: +50%
- **Ability:** *Impact* — Unleashes a forward shockwave crushing breakable barricades in front.
- **Unlock Requirement:** Collect 15,000 Credits.

---

### Character 4: NOVA (The Chrono-Battery)
- **Role:** Energy Specialist
- **Personality:** Quantum tech researcher fascinated by fracture ripples.
- **Visual Identity:** Holographic cowl, luminescent purple data circuits along limbs, levitating power core ornament.
- **Stats:**
  - Base Speed Modifier: 1.0x
  - Phase Generation Rate: 1.50x
  - Conventional Multiplier: 0.90x
- **Ability:** *Overcharge* — Magnifies all nearby energy collection and supercharges the Phase meter.
- **Unlock Requirement:** Activate Phase Shift 50 times.

---

### Character 5: MIRA (The Acrobat)
- **Role:** Trick Runner
- **Personality:** Aerialist and parkour thrill-seeker.
- **Visual Identity:** Neon emerald jumpsuited free-runner, stylized visor goggles, aerodynamic trailing ribbons.
- **Stats:**
  - Base Speed Modifier: 1.0x
  - Aerial Control Modifier: 1.35x
  - Stunt / Consecutive Action Multiplier: +25% per trick
- **Ability:** *Time Slip* — Distorts local time, slowing environmental speed by 40% for 3 seconds.
- **Unlock Requirement:** Achieve a 10x Combo in a single run.
